While the C based languages are the more difficult of the modern programming languages, C++ is widely used in robotics programming for its efficiency and the fine control of low-level systems that it offers.

The majority of our code is written in C++, so a decent understanding of the language is required.

Recommended Progression

You are not required to fully complete either of these courses. Skimming is completely fine.

If you start with the beginner course, continue with the intermediate course (skipping repeated content). If you start with the intermediate course, you do not need to complete the beginner course.

By the end of this section, you should be familiar with the following concepts and how to use them in C++:

  • Basic Syntax
  • Variables
  • Conditionals
  • Loops
  • Functions
  • Object-Oriented Programming (Classes and Objects)
  • Data Structures

Codecademy Courses
